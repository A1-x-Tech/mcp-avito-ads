# Авито Реклама: Статистика групп объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Статистика по перечисленным группам одной кампании: плоский массив, по записи на группу объявлений ({id, name, paymentModel, campaignType, data[] по дням, totalData за период}).

Техническое имя: `group_stats`

## Какую задачу решает

> Я хочу посмотреть статистику групп объявлений.

Статистика по перечисленным группам одной кампании: плоский массив, по записи на группу объявлений ({id, name, paymentModel, campaignType, data[] по дням, totalData за период}).

## Когда использовать

Используйте эту возможность, когда нужен результат «Статистика групп объявлений» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `campaignId` — **обязательно**. Кампания, группы которой попадают в отчёт. Id можно найти через list_campaigns.
- `dateFrom` — **обязательно**. Первый день периода, включительно (YYYY-MM-DD).
- `dateTo` — **обязательно**. Последний день периода, включительно (YYYY-MM-DD). Должен быть >= dateFrom, а период — не длиннее 100 дней.
- `groupIds` — **обязательно**. Id групп объявлений для отчёта, например [101, 102]. Обязательное поле; id даёт list_groups, а по всей кампании отчитывается campaign_stats.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Авито Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть статистику групп объявлений в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Метрики те же, что у campaign_stats — views (показы), clicks (клики), ctr, spend (расход), spendBonus, cpm, cpc, квартили видео, vtr, — деньги в рублях. Поле groupIds обязательно: инструмент сужает выборку, а не перечисляет её. Период включает обе границы, формат YYYY-MM-DD, длительность не больше 100 дней. Итогов по кампании не возвращает; чтобы охватить все группы кампании, есть campaign_stats с той же разбивкой. Тратит недельные баллы API; apiPointBalance в ответе — остаток до пополнения квоты в понедельник в 00:00 UTC, поэтому один широкий период предпочтительнее многих узких вызовов.

Доступ также зависит от прав токена, квот и ограничений исходного API.
