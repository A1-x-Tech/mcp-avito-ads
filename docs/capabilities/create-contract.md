# Авито Реклама: Зарегистрировать договор (ОРД) — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Регистрирует договор ОРД между аккаунтом и рекламодателем и возвращает {id} плюс apiPointBalance (остаток недельных баллов API).

Техническое имя: `create_contract`

## Какую задачу решает

> Я хочу зарегистрировать договор в ОРД.

Регистрирует договор ОРД между аккаунтом и рекламодателем и возвращает {id} плюс apiPointBalance (остаток недельных баллов API).

## Когда использовать

Используйте эту возможность, когда нужен результат «Зарегистрировать договор (ОРД)» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `advertiserId` — **обязательно**. Рекламодатель, с которым заключён договор (клиент). Id даёт list_advertisers.
- `type` — **обязательно**. Тип договора: service (оказание услуг), intermediary (посреднический), external (заключён вне Авито, определяется по cid).
- `counterpartyType` — **обязательно**. Тип контрагента — уходит в API в поле `description`: direct_with_advertiser или advertiser_intermediary.
- `subject` — **необязательно**. Предмет договора: org-distribution, mediation, distribution, representation, other. Обязателен для service и intermediary.
- `object` — **необязательно**. Действие по договору, поле API `object`: distribution, conclude, commercial, other. Обязательно для intermediary.
- `cid` — **необязательно**. Внешний идентификатор договора (со стороны ERID). Обязателен для типа external, для остальных отклоняется.
- `date` — **необязательно**. Дата договора, YYYY-MM-DD. Обязательна для service и intermediary.
- `number` — **необязательно**. Номер договора. Обязателен для service и intermediary.
- `isReportingRequired` — **необязательно**. Нужны ли по договору акты и отчёты. Обязательно для service и intermediary.
- `isFundsAllocationToPrincipal` — **необязательно**. Распределяются ли средства в пользу принципала. Обязательно для intermediary.
- `parentId` — **необязательно**. Id родительского договора. Задаётся, чтобы зарегистрировать дополнительное соглашение; тогда intermediary опускается.
- `intermediary` — **необязательно**. Юридические реквизиты исполнителя (посредника). Обязательны, если не задан parentId.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Авито Рекламе

Инструмент изменяет реальные данные Авито Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Зарегистрировать договор в ОРД в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Набор обязательных полей зависит от type: service требует subject, isReportingRequired, date и number (cid отклоняется); intermediary — всё то же плюс object и isFundsAllocationToPrincipal (cid отклоняется); external — только cid (parentId отклоняется). Юридические реквизиты исполнителя передаются в intermediary — они обязательны, если не задан parentId; с parentId запись становится дополнительным соглашением к тому договору, и intermediary в ней быть не должно. Эндпоинтов изменения и удаления нет, поэтому ошибочный договор остаётся на аккаунте навсегда.

Доступ также зависит от прав токена, квот и ограничений исходного API.
