# Авито Реклама: Список договоров — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Возвращает одну страницу договоров, зарегистрированных под аккаунтом: {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API).

Техническое имя: `list_contracts`

## Какую задачу решает

> Я хочу посмотреть договоров.

Возвращает одну страницу договоров, зарегистрированных под аккаунтом: {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API).

## Когда использовать

Используйте эту возможность, когда нужен результат «Список договоров» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `filter` — **необязательно**. Фильтр страницы. Без него возвращаются все договоры.
- `limit` — **необязательно**. Размер страницы, 1..100. По умолчанию 20.
- `page` — **необязательно**. Номер страницы, нумерация с 1. По умолчанию 1.

## Что вернёт

Возвращает одну страницу договоров, зарегистрированных под аккаунтом: {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API).

## Что изменится в Авито Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть договоров в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

В каждом элементе id, type, number, date, subject, object (действие по договору), cid, description (тип контрагента), parentId (заполнен у дополнительных соглашений) и юридические реквизиты клиента и исполнителя. Сузить выдачу можно через filter.ids / filter.numbers / filter.clients (id рекламодателей) / filter.contractors. limit — 1..100 (по умолчанию 20); нумерация page с 1.

Доступ также зависит от прав токена, квот и ограничений исходного API.
