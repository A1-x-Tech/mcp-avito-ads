# Авито Реклама: Создать аккаунт в песочнице — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** ТОЛЬКО ПЕСОЧНИЦА: создаёт тестовый аккаунт рекламодателя и возвращает его accountID.

Техническое имя: `create_sandbox_account`

## Какую задачу решает

> Я хочу создать аккаунт в песочнице.

ТОЛЬКО ПЕСОЧНИЦА: создаёт тестовый аккаунт рекламодателя и возвращает его accountID.

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать аккаунт в песочнице» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `inn` — **обязательно**. ИНН тестовой компании: 10 цифр для юрлица, 12 для ИП.
- `shortName` — **обязательно**. Краткое юридическое наименование, например "ООО Ромашка".
- `longName` — **обязательно**. Полное юридическое наименование, например "Общество с ограниченной ответственностью Ромашка".
- `ogrn` — **обязательно**. Государственный регистрационный номер (ОГРН для юрлица, ОГРНИП для ИП).
- `legalAddress` — **обязательно**. Юридический адрес.
- `actualAddress` — **обязательно**. Фактический почтовый адрес; может совпадать с legalAddress.
- `contact` — **обязательно**. Контактное лицо аккаунта; передаётся в API как есть и не может быть пустым, например {"name":"Иван Иванов","email":"ivan@example.com","phone":"+79001234567"}.
- `kpp` — **необязательно**. КПП. Есть у юрлиц (legalType ul); у ИП его нет — тогда поле опускается.
- `legalType` — **необязательно**. Организационно-правовая форма: ul — юрлицо, ip — ИП.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Авито Рекламе

Инструмент изменяет реальные данные Авито Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать аккаунт в песочнице в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Сервер отклоняет вызов, если не задано AVITO_ADS_ENVIRONMENT=sandbox, и такой отказ не стоит балла API. contact — непустой объект, например {"name":"Иван Иванов","email":"ivan@example.com","phone":"+79001234567"}; пустой отклоняется до отправки запроса. Два вызова создают два аккаунта. Изменить или удалить аккаунт нельзя, а сервер продолжает работать с AVITO_ADS_ACCOUNT_ID: новый id сам не подхватывается, для работы с ним его нужно прописать в конфигурации.

Доступ также зависит от прав токена, квот и ограничений исходного API.
