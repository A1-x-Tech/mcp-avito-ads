# Авито Реклама: Создать дочерний аккаунт без права оплаты — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Создаёт дочерний аккаунт без права оплаты под настроенным агентским аккаунтом и возвращает {accountID, clientKey, clientSecret} — собственные учётные данные API нового аккаунта, которые выдаются только здесь, поэтому сохранить их нужно сразу.

Техническое имя: `create_child_account`

## Какую задачу решает

> Я хочу создать дочерний аккаунт без права оплаты.

Создаёт дочерний аккаунт без права оплаты под настроенным агентским аккаунтом и возвращает {accountID, clientKey, clientSecret} — собственные учётные данные API нового аккаунта, которые выдаются только здесь, поэтому сохранить их нужно сразу.

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать дочерний аккаунт без права оплаты» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `shortName` — **обязательно**. Отображаемое название нового дочернего аккаунта, например "ООО Ромашка".
- `isSelfAdvertisingEnabled` — **обязательно**. Может ли новый аккаунт вести саморекламу (рекламировать собственные товары и услуги). Обязательное поле — значение указывается явно, флаг уходит в API при каждом создании.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Авито Рекламе

Инструмент изменяет реальные данные Авито Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать дочерний аккаунт без права оплаты в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Без права оплаты означает, что аккаунт не может пополнить свой баланс сам: деньги приходят из родительского через transfer_funds. Создать аккаунт с правом оплаты, переименовать или удалить аккаунт, а также прочитать секрет заново нельзя. Два вызова создают два аккаунта.

Доступ также зависит от прав токена, квот и ограничений исходного API.
