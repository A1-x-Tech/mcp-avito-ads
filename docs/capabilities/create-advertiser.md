# Авито Реклама: Зарегистрировать рекламодателя (ОРД) — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Регистрирует рекламодателя (контрагента ОРД) под аккаунтом и возвращает {id} плюс apiPointBalance (остаток недельных баллов API).

Техническое имя: `create_advertiser`

## Какую задачу решает

> Я хочу зарегистрировать рекламодателя в ОРД.

Регистрирует рекламодателя (контрагента ОРД) под аккаунтом и возвращает {id} плюс apiPointBalance (остаток недельных баллов API).

## Когда использовать

Используйте эту возможность, когда нужен результат «Зарегистрировать рекламодателя (ОРД)» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `inn` — **обязательно**. ИНН: 10 цифр для юрлица (ul), 12 для ИП (ip).
- `shortName` — **обязательно**. Краткое юридическое наименование, например "ООО Реклама".
- `longName` — **обязательно**. Полное юридическое наименование, например "Общество с ограниченной ответственностью Реклама".
- `ogrn` — **обязательно**. Государственный регистрационный номер (ОГРН для ul, ОГРНИП для ip).
- `legalAddress` — **обязательно**. Юридический адрес.
- `actualAddress` — **обязательно**. Фактический (почтовый) адрес; если он совпадает с legalAddress, повторяется тот же.
- `legalRole` — **обязательно**. Роль контрагента по ОРД: rd (рекламодатель), ra (агентство), rr (распространитель).
- `legalType` — **обязательно**. Тип юридического лица: ul (юрлицо) или ip (ИП).
- `kpp` — **необязательно**. КПП. Только для юрлиц (ul); для ip опускается.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Авито Рекламе

Инструмент изменяет реальные данные Авито Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Зарегистрировать рекламодателя в ОРД в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

На этот id ссылаются кампании и договоры. Юридические реквизиты должны совпадать с госреестром: inn (10 цифр для ul, 12 для ip), ogrn и оба адреса; kpp — только для юрлиц (ul). legalRole задаёт роль по ОРД: rd (рекламодатель), ra (агентство), rr (распространитель). Эндпоинтов изменения и удаления нет: ошибочного рекламодателя можно только заместить новым, поэтому сначала стоит поискать готовую запись через list_advertisers.

Доступ также зависит от прав токена, квот и ограничений исходного API.
