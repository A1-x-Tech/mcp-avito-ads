# Авито Реклама: Выдать пользователю доступ — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Выдаёт существующему пользователю Авито доступ к рекламному аккаунту с указанной ролью.

Техническое имя: `add_user`

## Какую задачу решает

> Я хочу выдать пользователю доступ.

Выдаёт существующему пользователю Авито доступ к рекламному аккаунту с указанной ролью.

## Когда использовать

Используйте эту возможность, когда нужен результат «Выдать пользователю доступ» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `userId` — **обязательно**. Числовой id пользователя Авито, которому выдаётся доступ, например 94235311.
- `role` — **обязательно**. admin — полный доступ, включая пользователей, переводы денег и правки кампаний; viewer — только чтение.

## Что вернёт

Возвращает подтверждение API плюс apiPointBalance.

## Что изменится в Авито Рекламе

Инструмент изменяет реальные данные Авито Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Выдать пользователю доступ в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

userId — числовой id пользователя Авито; пригласить по почте или телефону и создать аккаунт Авито этот инструмент не может. Если доступ уже есть, роль меняется через set_user_role.

Доступ также зависит от прав токена, квот и ограничений исходного API.
