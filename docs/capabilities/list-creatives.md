# Авито Реклама: Список креативов — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Перечисляет креативы аккаунта — сами объявления — постранично.

Техническое имя: `list_creatives`

## Какую задачу решает

> Я хочу посмотреть креативов.

Перечисляет креативы аккаунта — сами объявления — постранично.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список креативов» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Оставить креативы с этими id.
- `groupIds` — **необязательно**. Оставить креативы этих групп объявлений (по id).
- `campaignIds` — **необязательно**. Оставить креативы этих кампаний (по id).
- `statuses` — **необязательно**. Оставить креативы с этими статусами: draft, ready_for_moderation, in_moderation, moderation_failed, erir_registration, active, paused, stopped, finished, archived.
- `campaignTypes` — **необязательно**. Оставить только эти типы кампаний: textImage, HTML, video.
- `paymentModels` — **необязательно**. Оставить только эти модели оплаты: CPM, CPC.
- `advertisers` — **необязательно**. Оставить креативы этих рекламодателей (по id).
- `managers` — **необязательно**. Оставить креативы этих менеджеров — пользователей аккаунта (по id).
- `timeFrame` — **необязательно**. Оставить креативы, период размещения которых попадает в этот диапазон: {from, to}, YYYY-MM-DD.
- `filter` — **необязательно**. Универсальный фильтр: дополнительные ключи, которые подмешиваются в фильтр запроса как есть (в написании API). При конфликте побеждают именованные поля выше.
- `limit` — **необязательно**. Размер страницы, 1..100. По умолчанию 20.
- `page` — **необязательно**. Номер страницы, нумерация с 1. По умолчанию 1.

## Что вернёт

Возвращает {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API).

## Что изменится в Авито Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть креативов в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

У каждого креатива есть id, name, title, description, buttonText, link, status, groupID, campaignID, advertiserID, paymentModel, campaignType и legalInfo (данные рекламного реестра / ERID). Только чтение: загрузить, изменить, отправить на модерацию, приостановить или удалить креатив через этот API нельзя — изменять можно только бюджет и ставку группы объявлений.

Доступ также зависит от прав токена, квот и ограничений исходного API.
