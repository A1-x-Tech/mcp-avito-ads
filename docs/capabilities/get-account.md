# Авито Реклама: Реквизиты аккаунта — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Возвращает юридические реквизиты рекламного аккаунта, к которому привязан сервер: inn, kpp, ogrn, shortName, longName, legalAddress, actualAddress и блоки contact / manager.

Техническое имя: `get_account`

## Какую задачу решает

> Я хочу получить юридические реквизиты рекламного аккаунта, к которому привязан сервер.

Возвращает юридические реквизиты рекламного аккаунта, к которому привязан сервер: inn, kpp, ogrn, shortName, longName, legalAddress, actualAddress и блоки contact / manager.

## Когда использовать

Используйте эту возможность, когда нужен результат «Реквизиты аккаунта» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Возвращает юридические реквизиты рекламного аккаунта, к которому привязан сервер: inn, kpp, ogrn, shortName, longName, legalAddress, actualAddress и блоки contact / manager.

## Что изменится в Авито Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Получить юридические реквизиты рекламного аккаунта, к которому привязан сервер в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Аргументов не принимает — аккаунт задан в AVITO_ADS_ACCOUNT_ID и не выбирается для отдельного вызова. Денежных сумм не содержит (для них get_balance), данных кампаний тоже. Как и у всех инструментов здесь, в ответе есть apiPointBalance: остаток баллов API на текущую неделю (квота пополняется по понедельникам в 00:00 UTC).

Доступ также зависит от прав токена, квот и ограничений исходного API.
