# Авито Реклама: Изменить ставку группы объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Задаёт ставку одной группы объявлений (в API она называется price) в рублях (не меньше 1).

Техническое имя: `change_group_price`

## Какую задачу решает

> Я хочу изменить ставку группы объявлений.

Задаёт ставку одной группы объявлений (в API она называется price) в рублях (не меньше 1).

## Когда использовать

Используйте эту возможность, когда нужен результат «Изменить ставку группы объявлений» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `groupId` — **обязательно**. Id изменяемой группы объявлений, из list_groups.
- `price` — **обязательно**. Новая ставка в рублях, не меньше 1. Заменяет текущее значение.

## Что вернёт

Возвращает подтверждение API плюс apiPointBalance.

## Что изменится в Авито Рекламе

Инструмент изменяет реальные данные Авито Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Изменить ставку группы объявлений в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Единица зависит от paymentModel группы: рубли за 1000 показов при CPM, рубли за клик при CPC. Значение заменяет текущую ставку, а не прибавляется к ней, поэтому повторный вызов безопасен. Принимают его только группы с ручным управлением ставками. Изменить бюджет (для него есть change_group_budget) или статус группы нельзя — приостановить, возобновить или удалить группу этот API вообще не умеет. Текущую ставку показывает поле price в list_groups.

Доступ также зависит от прав токена, квот и ограничений исходного API.
