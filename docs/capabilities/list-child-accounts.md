# Авито Реклама: Дочерние аккаунты — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Перечисляет дочерние (суб-)аккаунты настроенного агентского аккаунта.

Техническое имя: `list_child_accounts`

## Какую задачу решает

> Я хочу посмотреть дочерние аккаунты.

Перечисляет дочерние (суб-)аккаунты настроенного агентского аккаунта.

## Когда использовать

Используйте эту возможность, когда нужен результат «Дочерние аккаунты» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Возвращает всех дочерних за один вызов: без постраничной выдачи, фильтров и поиска.

## Что изменится в Авито Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть дочерние аккаунты в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Каждая запись — {account:{id,shortName}, contract}. Балансов здесь НЕТ, для них есть list_child_accounts_with_balances. `apiPointBalance` в любом ответе этого сервера — остаток баллов API на текущую неделю (квота пополняется по понедельникам в 00:00 UTC); по нему и стоит рассчитывать частоту вызовов.

Доступ также зависит от прав токена, квот и ограничений исходного API.
