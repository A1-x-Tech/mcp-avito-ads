# Авито Реклама: Отозвать доступ пользователя — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Отзывает доступ пользователя к рекламному аккаунту.

Техническое имя: `delete_user`

## Какую задачу решает

> Я хочу отозвать доступ пользователя.

Отзывает доступ пользователя к рекламному аккаунту.

## Когда использовать

Используйте эту возможность, когда нужен результат «Отозвать доступ пользователя» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `userId` — **обязательно**. Числовой id пользователя Авито, которого нужно убрать из аккаунта, как его возвращает list_users.

## Что вернёт

Возвращает подтверждение API плюс apiPointBalance.

## Что изменится в Авито Рекламе

Исходный код помечает весь вызов «Отозвать доступ пользователя» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Отозвать доступ пользователя в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Операция разрушительная: вернуть доступ можно только через add_user с явно указанной ролью. Аккаунт Авито этого человека, его кампании и историю расходов не удаляет.

Доступ также зависит от прав токена, квот и ограничений исходного API.
