# MCP-возможности Авито Рекламы

Каталог содержит 25 публичных страниц — по одной для каждого зарегистрированного MCP-инструмента (tool) репозитория `mcp-avito-ads`. Страницы начинаются с задачи пользователя, объясняют результат и отдельно показывают, изменит ли вызов реальные данные.

Используйте этот каталог для выбора готовой возможности. Полные схемы параметров и ответы API остаются в [техническом справочнике](../TOOLS.md).

## Пользователи

- [Выдать пользователю доступ](./add-user.md) — Выдаёт существующему пользователю Авито доступ к рекламному аккаунту с указанной ролью. **Воздействие:** изменяет данные.
- [Отозвать доступ пользователя](./delete-user.md) — Отзывает доступ пользователя к рекламному аккаунту. **Воздействие:** опасная операция.
- [Пользователи аккаунта](./list-users.md) — Перечисляет пользователей с доступом к рекламному аккаунту — по одной записи {id, role, hasLoggedIn} на пользователя, где role это admin или viewer, а hasLoggedIn показывает, входил ли приглашённый хоть раз. **Воздействие:** только чтение.
- [Изменить роль пользователя](./set-user-role.md) — Меняет роль пользователя, у которого уже есть доступ к рекламному аккаунту. **Воздействие:** изменяет данные.

## Статистика

- [Статистика кампании](./campaign-stats.md) — Статистика ОДНОЙ кампании за период дат с разбивкой по группам и креативам: {campaign, groups[], creatives[]}. **Воздействие:** только чтение.
- [Статистика креативов](./creative-stats.md) — Статистика по перечисленным креативам одной кампании: плоский массив, по записи на креатив ({id, name, groupId, paymentModel, campaignType, data[] по дням, totalData за период}). **Воздействие:** только чтение.
- [Статистика групп объявлений](./group-stats.md) — Статистика по перечисленным группам одной кампании: плоский массив, по записи на группу объявлений ({id, name, paymentModel, campaignType, data[] по дням, totalData за период}). **Воздействие:** только чтение.

## Кампании, группы и креативы

- [Изменить бюджет группы объявлений](./change-group-budget.md) — Задаёт бюджет одной группы объявлений в рублях (не меньше 1). **Воздействие:** изменяет данные.
- [Изменить ставку группы объявлений](./change-group-price.md) — Задаёт ставку одной группы объявлений (в API она называется price) в рублях (не меньше 1). **Воздействие:** изменяет данные.
- [Список рекламных кампаний](./list-campaigns.md) — Перечисляет рекламные кампании аккаунта постранично. **Воздействие:** только чтение.
- [Список креативов](./list-creatives.md) — Перечисляет креативы аккаунта — сами объявления — постранично. **Воздействие:** только чтение.
- [Список групп объявлений](./list-groups.md) — Перечисляет группы объявлений аккаунта постранично. **Воздействие:** только чтение.

## ОРД: рекламодатели и договоры

- [Зарегистрировать рекламодателя (ОРД)](./create-advertiser.md) — Регистрирует рекламодателя (контрагента ОРД) под аккаунтом и возвращает {id} плюс apiPointBalance (остаток недельных баллов API). **Воздействие:** изменяет данные.
- [Зарегистрировать договор (ОРД)](./create-contract.md) — Регистрирует договор ОРД между аккаунтом и рекламодателем и возвращает {id} плюс apiPointBalance (остаток недельных баллов API). **Воздействие:** изменяет данные.
- [Список рекламодателей](./list-advertisers.md) — Возвращает одну страницу рекламодателей, зарегистрированных под аккаунтом: {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API). **Воздействие:** только чтение.
- [Список договоров](./list-contracts.md) — Возвращает одну страницу договоров, зарегистрированных под аккаунтом: {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API). **Воздействие:** только чтение.

## Дочерние аккаунты и деньги

- [Создать дочерний аккаунт без права оплаты](./create-child-account.md) — Создаёт дочерний аккаунт без права оплаты под настроенным агентским аккаунтом и возвращает {accountID, clientKey, clientSecret} — собственные учётные данные API нового аккаунта, которые выдаются только здесь, поэтому сохранить их нужно сразу. **Воздействие:** изменяет данные.
- [Дочерние аккаунты](./list-child-accounts.md) — Перечисляет дочерние (суб-)аккаунты настроенного агентского аккаунта. **Воздействие:** только чтение.
- [Дочерние аккаунты с балансами](./list-child-accounts-with-balances.md) — Тот же список, что и list_child_accounts, плюс баланс каждого дочернего аккаунта: {balance, bonusBalance} в рублях и бонусных рублях. **Воздействие:** только чтение.
- [Перевести бонусные рубли на другой аккаунт](./transfer-bonus.md) — Переводит бонусные рубли (`bonusBalance` — промо-средства, которыми можно оплачивать рекламу, но нельзя вывести деньгами) с настроенного аккаунта на другой: `amount` бонусных рублей, минимум 1. **Воздействие:** опасная операция.
- [Перевести деньги на другой аккаунт](./transfer-funds.md) — Переводит РЕАЛЬНЫЕ ДЕНЬГИ с настроенного аккаунта на другой (обычно на один из дочерних): `amount` рублей, минимум 1. **Воздействие:** опасная операция.

## Аккаунт

- [Создать аккаунт в песочнице](./create-sandbox-account.md) — ТОЛЬКО ПЕСОЧНИЦА: создаёт тестовый аккаунт рекламодателя и возвращает его accountID. **Воздействие:** изменяет данные.
- [Реквизиты аккаунта](./get-account.md) — Возвращает юридические реквизиты рекламного аккаунта, к которому привязан сервер: inn, kpp, ogrn, shortName, longName, legalAddress, actualAddress и блоки contact / manager. **Воздействие:** только чтение.
- [Баланс аккаунта](./get-balance.md) — Возвращает текущий баланс настроенного рекламного аккаунта в рублях: balance (реальные деньги) и bonusBalance (бонусные рубли, которые можно тратить только на рекламу). **Воздействие:** только чтение.

## Дополнительные методы API

- [Прямой вызов API Авито Рекламы](./raw-request.md) — Универсальный запрос к любому пути API Авито Рекламы — для эндпоинтов, у которых нет отдельного инструмента, например GET "v1/account/{accountID}/balance" или POST "v1/account/{accountID}/campaigns". **Воздействие:** опасная операция.
