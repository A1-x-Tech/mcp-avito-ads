# Авито Реклама: Список рекламных кампаний — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Перечисляет рекламные кампании аккаунта постранично.

Техническое имя: `list_campaigns`

## Какую задачу решает

> Я хочу посмотреть рекламных кампаний.

Перечисляет рекламные кампании аккаунта постранично.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список рекламных кампаний» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Оставить кампании с этими id.
- `statuses` — **необязательно**. Оставить кампании с этими статусами: draft, in_moderation, moderation_failed, partial_moderation, active, paused, stopped, finished, archived.
- `campaignTypes` — **необязательно**. Оставить только эти типы кампаний: textImage, HTML, video.
- `paymentModels` — **необязательно**. Оставить только эти модели оплаты: CPM, CPC.
- `advertisers` — **необязательно**. Оставить кампании этих рекламодателей (по id).
- `managers` — **необязательно**. Оставить кампании этих менеджеров — пользователей аккаунта (по id).
- `contractIds` — **необязательно**. Оставить кампании по этим договорам (по id).
- `additionalAgreementIds` — **необязательно**. Оставить кампании по этим дополнительным соглашениям (по id).
- `createdAt` — **необязательно**. Оставить кампании, созданные в этом диапазоне: {from, to}, YYYY-MM-DD.
- `timeFrame` — **необязательно**. Оставить кампании, период размещения которых попадает в этот диапазон: {from, to}, YYYY-MM-DD.
- `filter` — **необязательно**. Универсальный фильтр: дополнительные ключи, которые подмешиваются в фильтр запроса как есть (в написании API). При конфликте побеждают именованные поля выше.
- `limit` — **необязательно**. Размер страницы, 1..100. По умолчанию 20.
- `page` — **необязательно**. Номер страницы, нумерация с 1. По умолчанию 1.

## Что вернёт

Возвращает {total, items, page, limit, hasNextPage} плюс apiPointBalance — остаток недельных баллов API, которые пополняются по понедельникам в 00:00 UTC.

## Что изменится в Авито Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть рекламных кампаний в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

У каждой кампании есть id, name, status, budget (рубли), paymentModel (CPM/CPC), campaignType, startDate/endDate, advertiserId, contractId, managerID и отметки времени. Поля фильтра объединяются по И, и каждый список оставляет только перечисленные в нём значения. Через этот API нельзя создать, изменить, приостановить, возобновить, заархивировать или удалить кампанию и нельзя тронуть её таргетинг — единственные доступные где-либо изменения это change_group_budget и change_group_price для группы объявлений.

Доступ также зависит от прав токена, квот и ограничений исходного API.
