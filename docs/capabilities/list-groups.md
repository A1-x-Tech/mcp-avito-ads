# Авито Реклама: Список групп объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Перечисляет группы объявлений аккаунта постранично.

Техническое имя: `list_groups`

## Какую задачу решает

> Я хочу посмотреть групп объявлений.

Перечисляет группы объявлений аккаунта постранично.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список групп объявлений» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Оставить группы объявлений с этими id.
- `campaignIds` — **необязательно**. Оставить группы этих кампаний (по id).
- `statuses` — **необязательно**. Оставить группы с этими статусами: draft, in_moderation, moderation_failed, will_launch_soon, active, will_stop_soon, pausing, paused, unpausing, stopped, finished, archived.
- `paymentModels` — **необязательно**. Оставить только эти модели оплаты: CPM, CPC.
- `paces` — **необязательно**. Оставить группы с этими режимами распределения бюджета. Значения произвольные: фиксированного словаря для этого фильтра в SDK нет.
- `advertisers` — **необязательно**. Оставить группы этих рекламодателей (по id).
- `managers` — **необязательно**. Оставить группы этих менеджеров — пользователей аккаунта (по id).
- `timeFrame` — **необязательно**. Оставить группы, период размещения которых попадает в этот диапазон: {from, to}, YYYY-MM-DD.
- `filter` — **необязательно**. Универсальный фильтр: дополнительные ключи, которые подмешиваются в фильтр запроса как есть (в написании API). При конфликте побеждают именованные поля выше.
- `limit` — **необязательно**. Размер страницы, 1..100. По умолчанию 20.
- `page` — **необязательно**. Номер страницы, нумерация с 1. По умолчанию 1.

## Что вернёт

Возвращает {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API).

## Что изменится в Авито Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть групп объявлений в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Группа — тот уровень, на котором лежат деньги: в каждом элементе id, name, campaignID, status, budget и price (ставка) в рублях, paymentModel, campaignType, advertiserID, haveCreative и отметки времени. Эти два числа меняют change_group_budget / change_group_price — других изменяемых полей во всём дереве рекламных объектов нет. Создать, переименовать, приостановить, возобновить или удалить группу здесь нельзя, таргетинг групп не выведен.

Доступ также зависит от прав токена, квот и ограничений исходного API.
