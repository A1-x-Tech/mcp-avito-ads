# Авито Реклама: Изменить роль пользователя — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Меняет роль пользователя, у которого уже есть доступ к рекламному аккаунту.

Техническое имя: `set_user_role`

## Какую задачу решает

> Я хочу изменить роль пользователя.

Меняет роль пользователя, у которого уже есть доступ к рекламному аккаунту.

## Когда использовать

Используйте эту возможность, когда нужен результат «Изменить роль пользователя» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `userId` — **обязательно**. Числовой id пользователя Авито, как его возвращает list_users.
- `role` — **обязательно**. admin — полный доступ, включая пользователей, переводы денег и правки кампаний; viewer — только чтение.

## Что вернёт

Возвращает подтверждение API плюс apiPointBalance.

## Что изменится в Авито Рекламе

Инструмент изменяет реальные данные Авито Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Изменить роль пользователя в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Назначение той же роли, что стоит сейчас, ничего не меняет. Доступ не выдаёт (для этого add_user) и не отзывает (для этого delete_user).

Доступ также зависит от прав токена, квот и ограничений исходного API.
