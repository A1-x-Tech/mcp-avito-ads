# Авито Реклама: Прямой вызов API Авито Рекламы — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Универсальный запрос к любому пути API Авито Рекламы — для эндпоинтов, у которых нет отдельного инструмента, например GET "v1/account/{accountID}/balance" или POST "v1/account/{accountID}/campaigns".

Техническое имя: `raw_request`

## Какую задачу решает

> Я хочу выполнить дополнительный запрос к API.

Универсальный запрос к любому пути API Авито Рекламы — для эндпоинтов, у которых нет отдельного инструмента, например GET "v1/account/{accountID}/balance" или POST "v1/account/{accountID}/campaigns".

## Когда использовать

Используйте эту возможность, когда нужен результат «Прямой вызов API Авито Рекламы» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `path` — **обязательно**. Путь API, например "v1/account/{accountID}/groups" или "v1/account/{accountID}/campaigns/123/stats".
- `method` — **необязательно**. HTTP-метод. По умолчанию GET.
- `body` — **необязательно**. Тело запроса в JSON, например {"filter":{},"limit":20,"page":1} для эндпоинта списка.
- `confirmWrite` — **необязательно**. Для POST и DELETE должен быть true. Установка флага подтверждает, что путь может писать: funds-transfer и delete-user — такие же POST/DELETE, как и любое чтение списка.

## Что вернёт

Возвращает сырой ответ плюс apiPointBalance (остаток недельных баллов).

## Что изменится в Авито Рекламе

Исходный код помечает весь вызов «Прямой вызов API Авито Рекламы» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить дополнительный запрос к API в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Пути задаются относительно базы API и привязаны к аккаунту: подстановка {accountID} заменяется на настроенный id аккаунта, путь с другим аккаунтом отклоняется, как и путь, выходящий за базу API. `body` отправляется как JSON. Через него доступны все пишущие эндпоинты — funds-transfer, bonus-transfer, delete-user и create-*, — причём без клиентских проверок, которые делают отдельные инструменты, и ничего из этого не отменить; когда специальный инструмент есть, лучше взять его: transfer_funds / delete_user / create_*. confirmWrite=true — явное подтверждение того, что путь может писать, поэтому перед установкой флага путь стоит проверить: POST используется и для безобидных чтений — списков и статистики, — которым флаг тоже нужен. GET выполняется без ограничений.

Доступ также зависит от прав токена, квот и ограничений исходного API.

Связанных специализированных инструментов в этой группе нет.
