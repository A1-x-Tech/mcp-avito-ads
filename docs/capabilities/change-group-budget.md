# Авито Реклама: Изменить бюджет группы объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Задаёт бюджет одной группы объявлений в рублях (не меньше 1).

Техническое имя: `change_group_budget`

## Какую задачу решает

> Я хочу изменить бюджет группы объявлений.

Задаёт бюджет одной группы объявлений в рублях (не меньше 1).

## Когда использовать

Используйте эту возможность, когда нужен результат «Изменить бюджет группы объявлений» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `groupId` — **обязательно**. Id изменяемой группы объявлений, из list_groups.
- `budget` — **обязательно**. Новый бюджет в рублях, не меньше 1. Заменяет текущее значение.

## Что вернёт

Возвращает подтверждение API плюс apiPointBalance.

## Что изменится в Авито Рекламе

Инструмент изменяет реальные данные Авито Рекламы так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Изменить бюджет группы объявлений в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Значение заменяет текущий бюджет, а не прибавляется к нему, поэтому повторный вызов безопасен. Принимают его только группы с ручным управлением ставками, остальным API отказывает. Изменить бюджет кампании, ставку (для неё есть change_group_price) или статус группы нельзя — приостановить, возобновить или удалить группу этот API вообще не умеет. Текущий бюджет стоит сначала посмотреть через list_groups.

Доступ также зависит от прав токена, квот и ограничений исходного API.
