# Авито Реклама: Список рекламодателей — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Возвращает одну страницу рекламодателей, зарегистрированных под аккаунтом: {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API).

Техническое имя: `list_advertisers`

## Какую задачу решает

> Я хочу посмотреть рекламодателей.

Возвращает одну страницу рекламодателей, зарегистрированных под аккаунтом: {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API).

## Когда использовать

Используйте эту возможность, когда нужен результат «Список рекламодателей» без ручной работы в интерфейсе Авито Рекламы. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `filter` — **необязательно**. Фильтр страницы. Без него возвращаются все рекламодатели.
- `limit` — **необязательно**. Размер страницы, 1..100. По умолчанию 20.
- `page` — **необязательно**. Номер страницы, нумерация с 1. По умолчанию 1.

## Что вернёт

Возвращает одну страницу рекламодателей, зарегистрированных под аккаунтом: {total, items, page, limit, hasNextPage} плюс apiPointBalance (остаток недельных баллов API).

## Что изменится в Авито Рекламе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть рекламодателей в Авито Рекламе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

В каждом элементе id, shortName, longName, inn, ogrn, kpp, legalAddress, actualAddress, legalType (ul|ip) и legalRole (rd|ra|rr). Сузить выдачу можно через filter.ids / filter.inns / filter.roles; полнотекстового поиска нет, совпадения по названиям придётся искать самостоятельно. limit — 1..100 (по умолчанию 20); нумерация page с 1.

Доступ также зависит от прав токена, квот и ограничений исходного API.
