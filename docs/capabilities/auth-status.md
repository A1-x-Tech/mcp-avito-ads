# Авито Реклама: Статус подключения — MCP-инструмент (tool)

**MCP-инструмент (tool) для Авито Рекламы:** Показывает, готов ли сервер работать: какие переменные заданы, нет ли среди них испорченного значения, какое окружение и адрес API используются.

Техническое имя: `auth_status`

## Какую задачу решает

> Я хочу понять, почему инструменты Авито Рекламы отказывают, и что именно чинить.

Отвечает на вопрос «что не так с настройкой» из локального состояния, не обращаясь к API. Видно, заданы ли `AVITO_ADS_CLIENT_ID`, `AVITO_ADS_CLIENT_SECRET` и `AVITO_ADS_ACCOUNT_ID`, какое из значений сервер счёл испорченным, выбрано ли окружение `production` или `sandbox` и на какой адрес API уходят запросы.

## Когда использовать

Вызывайте первым, когда любой инструмент отвечает, что учётных данных нет, что аккаунт не найден или отдаёт пустой 403. Без этого единственный доступный сигнал — одна и та же ошибка на каждом вызове, из которой не видно, какая именно переменная виновата.

## Что нужно передать

Параметры не нужны.

## Что вернёт

Признак готовности, наличие client id и client secret (сами значения не возвращаются), id рекламного аккаунта, окружение, адрес API, список незаданных переменных и — если значение испорчено — код причины с пояснением, что именно не так.

## Что изменится в Авито Рекламе

Ничего. Инструмент читает локальную конфигурацию и не делает ни одного запроса к API.

## Пример запроса

> Проверь статус подключения к Авито Рекламе: всё ли настроено и какой аккаунт указан.

## Возможные ошибки и ограничения

Показывает локальное состояние, а не права ключа: переменные могут быть заполнены верно, а ключ — выдан для другого рекламного аккаунта. Такой случай виден по ответам API, и подсказка в ответе об этом говорит: пустой 403 без текста означает чужой `AVITO_ADS_ACCOUNT_ID`, а 401 — неверную пару client id/secret. Переменные читаются один раз при старте, поэтому после правки конфигурации сервер нужно перезапустить. Client secret и токен инструмент не возвращает никогда.
